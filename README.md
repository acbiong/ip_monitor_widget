# 本机状态监视器

Linux/deepin 桌面状态监视器，支持多网卡本机 IP、公网 IP、默认出口网卡、上传下载速度、CPU、内存、硬盘和 CPU 温度显示。

## 快速开始

- 直接运行单文件：`dist/DesktopMonitor-deepin25-x86_64`
- 推荐传输包：`dist/DesktopMonitor-deepin25-x86_64.tar.gz`
- 详细构建与使用说明：`docs/README.md`
- 项目文件和目录清单：`tables/PROJECT_FILE_INVENTORY.md`
- 当前基础版本：`0.7.0`；完整构建版本见 `src/VERSION.json`
