# 软件开发规格书

版本：0.8.0　日期：2026-09-20

## 1. 软件定位

本软件是 Linux/deepin 桌面状态监视器，使用无边框、半透明、白色文字的固定置底窗口显示网络和系统指标，并通过系统托盘提供设置、锁定、还原位置和退出操作。

## 2. 功能规格

- 采集并显示每个当前在线网卡的本机 IPv4/IPv6 地址。
- 通过本地地址和网卡绑定分别查询每张网卡的公网 IP；查询失败显示“未连接公网”，不得复用其他网卡结果。
- 检测并显示 IPv4/IPv6 默认出口网卡，默认出口判断独立于公网查询。
- 显示全局上传/下载速率、CPU、内存、根文件系统使用率和 CPU 温度。
- 支持字体大小、背景透明度、刷新周期实时预览；取消设置回滚，恢复默认一键生效。
- 主窗口和设置窗口分别保存位置；窗口可拖动，锁定后鼠标穿透，主窗口始终置于普通窗口底部；主窗口使用工具窗口类型，只显示系统托盘图标，不显示任务栏入口。
- 提供 PyInstaller 单文件发布，内置 Python、Qt、Python 依赖、CA 证书和路由检测工具。
- 托盘“关于”页面显示软件版本、开发者、Git 分支/提交/状态和编译目标信息。

## 3. 非功能规格

- 普通用户权限运行，不开放本地服务端口；监测保持只读，仅用户明确选择托盘默认出口时，通过 NetworkManager 授权临时修改路由优先级，不写入永久连接配置。
- Qt 主线程只负责界面；公网查询和路由检查异步执行，并设置超时和退出清理。
- UI 文本不得因网卡名称、地址或字号变化而遮挡；内容超过屏幕时使用滚动区域。
- 模块按职责独立文件，公共常量集中管理；新增行为必须有文档和测试记录。
- 版本采用 SemVer：基础版本为 `MAJOR.MINOR.PATCH`，每次编译追加 `+build.YYYYMMDD.N`。

## 4. 架构约束

入口为 `src/main.py`；配置常量在 `config.py`；网络、默认路由、公网查询、指标采集、设置、界面、托盘分别由独立模块实现。`src/version.py` 只读 `VERSION.json`，`src/packaging/version_manager.py` 是唯一的版本状态写入工具。

## 5. 质量门禁

代码必须通过语法检查、模块/集成回归、交付自检和图形冒烟测试；报告放在 `docs/test_reports/`，计划放在 `docs/test_plan/`。未通过的测试不得用成功状态覆盖报告。构建还必须生成依赖审计、manifest、SHA256 校验和及第三方许可归档。

## 6. 兼容边界

当前发布基线为 deepin 25、x86_64、glibc 2.38+、X11 或可用 XWayland。单文件不能替代目标机内核、glibc、显示服务器、显卡驱动或桌面托盘服务，因此不能宣称兼容所有 deepin 版本和架构。

### 0.6.1 关于窗口布局约束

关于窗口标题仅为“关于”，软件名称水平居中；尺寸由内容和系统字体确定后固定，不允许用户缩放，不改变主窗口或设置窗口行为。

### 0.6.2 设置窗口显示约束

设置页独立使用黑色文字和不透明浅色背景，标签、输入框、按钮不继承桌面监视器的白字样式。使用系统字号，预览时不随监视器字体或透明度改变；窗口按内容固定尺寸，保留位置记忆、保存、取消回滚和还原默认设置。

### 0.7.0 默认出口切换

- 托盘“默认出口”二级菜单枚举在线且具有有效 IP 的网卡，依据主路由表勾选当前 IPv4/IPv6 出口；两个地址族使用不同网卡时允许分别勾选并标注。
- 每次打开菜单重新读取，二级菜单保持打开时每 3 秒刷新；切换中禁止重复操作，失败不乐观修改勾选。
- 只支持 NetworkManager 1.42+ 管理、已有主表默认路由的连接。虚拟网卡无网关、未管理、活动 VPN、实际接管默认出口或不支持的策略规则、系统策略拒绝时禁用并解释原因，不凭空配置网关。
- 调整目标已有默认路由的地址族；目标没有 IPv6 默认路由时保留其他网卡 IPv6 出口，不伪称全流量均已切换。默认路由不等于公网连通性保证。
- 通过连接 UUID、应用配置版本、检查点和重新读取主路由表防止过期操作、拒权或中途断网被误报成功。
- 使用内置 dbus-next 调用系统 NetworkManager/Polkit；不调用 sudo，不把 GUI 提权，不收集或保存密码。
- 修改临时生效，重连后由系统配置重新决定；失败回滚，意外退出由 90 秒系统检查点兜底。回滚失败须明确提示，不隐瞒网络可能仍有变化。

### 0.7.1 VPN DNS 代理兼容

公网回显 HTTPS 仍绑定指定源地址和设备，不使用环境代理。DNS 优先尝试设备绑定查询，失败后在剩余预算内使用系统解析器，兼容 Tailscale 等非回环本机/VPN DNS 代理。DNS 解析路径不用于判定公网出口；不得把系统默认出口的 HTTPS 结果填入其他网卡。不修改 DNS、VPN 或系统路由。

### 0.7.2 策略路由兼容

不得仅凭存在非内置规则就禁用所有网卡。按优先级评估未标记普通流量到主路由表的路径：非零 fwmark 专用规则保持不变；先于主表查询的自定义表只含局部网段路由时允许切换主表。表中含默认/半网段/合并覆盖全网的路由，或否定、源网段、抑制前缀等暂不支持的选择条件时，继续阻止并说明原因。必须明确主表切换不接管 VPN/专用流量。
不更改现有授权、连接版本校验、检查点回滚和永久配置边界；菜单可用不代表目前存在第二张合格出口网卡。

### 0.8.0 公网获取间隔

配置 `public_ip_interval` 为秒制整数，默认 60，范围 10–3600；与毫秒制系统指标 `interval` 独立。
公网计时器持续工作，不依赖本机 IP 变化；设置支持即时预览、保存、取消回滚和还原默认，旧配置缺失新键时自动使用 60 秒。
预览其他设置不得重置公网倒计时。退出停止计时器并清理子进程，保留未保存预览退出时只写原配置的行为。
查询进行中不得重复启动；定时触发不等同保证公网回显响应时间。
