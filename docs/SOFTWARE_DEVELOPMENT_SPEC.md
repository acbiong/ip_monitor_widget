# 软件开发规格书

版本：0.5.1　日期：2026-09-20

## 1. 软件定位

本软件是 Linux/deepin 桌面状态监视器，使用无边框、半透明、白色文字的固定置底窗口显示网络和系统指标，并通过系统托盘提供设置、锁定、还原位置和退出操作。

## 2. 功能规格

- 采集并显示每个当前在线网卡的本机 IPv4/IPv6 地址。
- 通过本地地址和网卡绑定分别查询每张网卡的公网 IP；查询失败显示“未连接公网”，不得复用其他网卡结果。
- 检测并显示 IPv4/IPv6 默认出口网卡，默认出口判断独立于公网查询。
- 显示全局上传/下载速率、CPU、内存、根文件系统使用率和 CPU 温度。
- 支持字体大小、背景透明度、刷新周期实时预览；取消设置回滚，恢复默认一键生效。
- 主窗口和设置窗口分别保存位置；窗口可拖动，锁定后鼠标穿透，主窗口始终置于普通窗口底部；主窗口使用工具窗口类型，只显示系统托盘图标，不显示任务栏入口。
- 提供 PyInstaller 单文件发布，内置 Python、Qt、Python 依赖、CA 证书和路由检测工具。

## 3. 非功能规格

- 普通用户权限运行，不修改网络配置，不开放本地服务端口。
- Qt 主线程只负责界面；公网查询和路由检查异步执行，并设置超时和退出清理。
- UI 文本不得因网卡名称、地址或字号变化而遮挡；内容超过屏幕时使用滚动区域。
- 模块按职责独立文件，公共常量集中管理；新增行为必须有文档和测试记录。
- 版本采用 SemVer：基础版本为 `MAJOR.MINOR.PATCH`，每次编译追加 `+build.YYYYMMDD.N`。

## 4. 架构约束

入口为 `src/main.py`；配置常量在 `config.py`；网络、默认路由、公网查询、指标采集、设置、界面、托盘分别由独立模块实现。`src/version.py` 只读 `VERSION.json`，`src/packaging/version_manager.py` 是唯一的版本状态写入工具。

## 5. 质量门禁

代码必须通过语法检查、模块/集成回归、交付自检和图形冒烟测试；报告放在 `docs/test_reports/`，计划放在 `docs/test_plan/`。未通过的测试不得用成功状态覆盖报告。构建还必须生成依赖审计、manifest、SHA256 校验和及第三方许可归档。

## 6. 兼容边界

当前发布基线为 deepin 25、x86_64、glibc 2.38+、X11 或可用 XWayland。单文件不能替代目标机内核、glibc、显示服务器、显卡驱动或桌面托盘服务，因此不能宣称兼容所有 deepin 版本和架构。
