# 测试计划

版本：0.7.0

## 1. 目的

验证本机状态监视器在多网卡、网络切换、桌面显示、设置预览、退出清理和单文件交付场景下满足软件规格书要求，并为每次功能更新、缺陷修复和发布构建提供可重复的验收基线。

## 2. 测试层级

| 层级 | 范围 | 触发时机 |
|---|---|---|
| 静态检查 | Python 语法、JSON、目录归类、版本状态 | 每次提交或构建前 |
| 模块测试 | 网络解析、默认路由、公网查询、设置存储、布局计算 | 对应模块变更后 |
| 集成测试 | Qt 主窗口、托盘、设置窗口、后台子进程、退出清理 | 功能更新或跨模块修改后 |
| 回归测试 | 多网卡、USB 网卡、vmnet、默认出口、置底、字体缩放、位置记忆 | 每次发布前 |
| 交付测试 | PyInstaller 单文件、依赖审计、隔离环境自检、图形冒烟测试 | 每次编译后 |

## 3. 核心用例

1. 单网卡在线：显示本机 IPv4/IPv6、独立公网 IP、上传下载速率和系统指标。
2. 多网卡在线：每张网卡单独显示本机地址和公网地址，不借用其他网卡结果。
3. 网卡断开或无有效地址：对应网卡自动隐藏；公网失败显示“未连接公网”。
4. 默认出口变化：分别更新 IPv4/IPv6 默认出口网卡，不以公网查询结果推断出口。
5. 设置预览：调整字体、透明度和刷新间隔时主窗口实时变化；取消后恢复打开设置前状态。
6. 字体缩放：主窗口字号和窗口尺寸按相同比例调整，长文本不被遮挡。
7. 锁定与置底：锁定后鼠标穿透，主窗口保持普通软件之下，不遮挡其他软件。
8. 位置记忆：主窗口和设置窗口分别保存位置；托盘还原位置后回到默认安全坐标。
9. 快速退出：托盘退出不等待公网请求超时，所有后台进程及时终止。
10. 单文件运行：清空外部 Python、PATH、Qt 插件路径后，`--self-test` 和 `--smoke-test` 均成功。
11. 关于页面：托盘菜单可打开，版本、开发者、Git 和编译信息均非空或明确显示未知。
12. Git 快照：覆盖干净、已修改、已暂存、未跟踪、被忽略、分离 HEAD、无仓库、无 Git、超时和状态命令失败；修改 VERSION.json 不能伪装干净。
13. 关于页连续打开/关闭两次后无残留对象；监视器白色字体和半透明背景不污染关于页。
14. 冻结包在没有 Git/Python 环境时仍读取内置编译快照，版本与 manifest 一致；快照先于构建号自动递增。

## 4. 发布门禁

- 静态检查、关键回归和交付测试全部通过。
- `src/VERSION.json` 的基础版本符合语义化版本格式，构建号大于上一次成功构建。
- `dist/SHA256SUMS` 能验证单文件和传输包。
- `docs/test_reports/` 中保存本次构建的自检、冒烟和验证报告。
- 若存在未解决的阻断缺陷，不得将构建标记为正式发布。

## 0.6.1 关于窗口布局回归

- 通过托盘打开关于页，确认窗口标题严格等于“关于”，软件名称居中。
- 尝试放大和缩小：窗口尺寸不变，最小尺寸、最大尺寸与当前尺寸一致。
- 连续打开/关闭两次，确认字段、图标和独立样式正常，无残留对话框。
- 源码和单文件均运行 `--smoke-test`；新增 `about_title`、`about_name_centered`、`about_fixed_size` 必须全为 true。

## 0.6.2 设置窗口样式与尺寸回归

- 通过真实托盘“打开设置”动作进入；检查标签、数值输入、按钮为黑字，背景为不透明浅色。
- 调整监视器字号至 48、透明度至 95%、间隔至 10000 ms，检查实时预览正确且设置页字号、透明度、尺寸不变。
- 尝试放大/缩小设置页，检查当前、最小、最大尺寸相等。
- 点击还原默认设置并检查预览；取消恢复原配置；第二次打开保存，检查临时 QSettings 记录正确且对话框已释放。
- 源码及单文件执行 `--smoke-test`；设置页所有 `settings_*` 检查为 true。

## 0.7.0 默认出口菜单与切换

- 使用 `QT_QPA_PLATFORM=offscreen QT_QPA_PLATFORMTHEME= python3 -B -m unittest discover -s src/tests -v` 运行回归，需先安装 requirements.txt；所有写操作由模拟对象代替。
- 覆盖 IPv4/IPv6、双栈与分离出口、同 metric 竞争、静态默认路由、无网关、链路断开、策略路由、连接 UUID 更换。
- 覆盖检查点拒权不修改、Reapply 失败回滚、验证失败回滚、取消回滚、回滚失败提示；验证不调用永久设置更新方法。
- 覆盖实际勾选、禁止乐观勾选、禁用 vmnet 项、断开隐藏及错误提示。
- 真实系统只读 `--default-route-control` list 并运行 GUI `--smoke-test`；核对实际默认出口，不自动执行真实切换。
- 单文件清空外部 Python/Qt/PATH 环境运行自检和冒烟；确认内置 dbus-next 和内部入口可用。
- 人工验收（需用户允许及两张有网关的网卡）：分别切换 IPv4/双栈，检查系统授权、路由和互联网连通性；断开目标或拒绝授权验证提示；重连确认永久配置未被修改。
