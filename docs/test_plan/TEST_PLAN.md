# 测试计划

版本：0.10.1

## 1. 目的

验证本机状态监视器在多网卡、网络切换、桌面显示、设置预览、退出清理和单文件交付场景下满足软件规格书要求，并为每次功能更新、缺陷修复和发布构建提供可重复的验收基线。

## 2. 测试层级

| 层级 | 范围 | 触发时机 |
|---|---|---|
| 静态检查 | Python 语法、JSON、目录归类、版本状态 | 每次提交或构建前 |
| 模块测试 | 网络解析、默认路由、公网查询、设置存储、布局计算 | 对应模块变更后 |
| 集成测试 | Qt 主窗口、托盘、设置窗口、后台子进程、退出清理 | 功能更新或跨模块修改后 |
| 回归测试 | 多网卡、USB 网卡、vmnet、默认出口、置底、字体缩放、位置记忆 | 每次发布前 |
| 交付测试 | PyInstaller 单文件、依赖审计、隔离环境自检、图形冒烟测试 | 每次编译后 |

## 3. 核心用例

1. 单网卡在线：显示本机 IPv4/IPv6、独立公网 IP、上传下载速率和系统指标。
2. 多网卡在线：每张网卡单独显示本机地址和公网地址，不借用其他网卡结果。
3. 网卡断开或无有效地址：对应网卡自动隐藏；公网失败显示“未连接公网”。
4. 默认出口变化：分别更新 IPv4/IPv6 默认出口网卡，不以公网查询结果推断出口。
5. 设置预览：调整字体、透明度和刷新间隔时主窗口实时变化；取消后恢复打开设置前状态。
6. 字体缩放：主窗口字号和窗口尺寸按相同比例调整，长文本不被遮挡。
7. 锁定与置底：锁定后鼠标穿透，主窗口保持普通软件之下，不遮挡其他软件。
8. 位置记忆：主窗口和设置窗口分别保存位置；托盘还原位置后回到默认安全坐标。
9. 快速退出：托盘退出不等待公网请求超时，所有后台进程及时终止。
10. 单文件运行：清空外部 Python、PATH、Qt 插件路径后，`--self-test` 和 `--smoke-test` 均成功。
11. 关于页面：托盘菜单可打开，版本、开发者、Git 和编译信息均非空或明确显示未知。
12. Git 快照：覆盖干净、已修改、已暂存、未跟踪、被忽略、分离 HEAD、无仓库、无 Git、超时和状态命令失败；修改 VERSION.json 不能伪装干净。
13. 关于页连续打开/关闭两次后无残留对象；监视器白色字体和半透明背景不污染关于页。
14. 冻结包在没有 Git/Python 环境时仍读取内置编译快照，版本与 manifest 一致；快照先于构建号自动递增。

## 4. 发布门禁

- 静态检查、关键回归和交付测试全部通过。
- `src/VERSION.json` 的基础版本符合语义化版本格式，构建号大于上一次成功构建。
- `dist/SHA256SUMS` 能验证单文件和传输包。
- `docs/test_reports/` 中保存本次构建的自检、冒烟和验证报告。
- 若存在未解决的阻断缺陷，不得将构建标记为正式发布。

## 0.7.1 公网 DNS 回退回归

- 模拟 Tailscale 非回环 DNS 代理不可经物理网卡访问，验证设备 DNS 失败后可限时回退系统 DNS。
- 覆盖设备解析成功、回环代理、IPv6 记录经 IPv4 DNS 查询、全部失败、零/耗尽预算、socket 错误及配置错误。
- 验证 HTTPS 源地址、SO_BINDTODEVICE、TLS 主机名和禁用代理约束未改变；vmnet 查询失败不得借用其他网卡结果。
- 在授权的当前网络执行真实 PublicIPService，确认无线成功而无外网网卡不借用结果，退出无剩余进程；不记录实际公网 IP。
- 全部 unittest、源码/单文件冒烟和打包自检通过后，使用新版单文件内部公网入口进行同网卡实测。

## 0.8.0 公网刷新间隔

- 校验旧配置缺省 60 秒、10–3600 边界、字符串/非法/非有限值处理及保存重载。
- 校验启动时秒转毫秒，预览修改计时器，取消恢复原值，保存持久化，默认按钮只发一次预览信号。
- 改动字体/透明度/指标间隔不得重启公网计时器；预览中退出保存原值，退出后不得再调度查询。
- 注入模拟公网服务、加速 Qt 计时器，保持本机地址不变，验证第二次自动查询把公网显示从旧值改为新值，不手动触发查询。
- 真实 X11 设置操作验证新字段可见、黑字及固定尺寸不回归，预览/默认/保存/取消与定时器同步。
- 新增 10 项独立测试；与原 60 项合计 70 项。单文件自检、GUI 冒烟及校验和通过后交付。

## 0.10.0 公网运营商

1. 常见登记别名转中文、未知名称保守标注、多源 ASN 不猜测。
2. 私网/保留/组播/无效输入不联网；前缀不包含请求 IP、ASN 编号错配、非法 JSON/超大响应降级。

4. 同地址去重、缓存有效期/失败重试、缓存上限、旧地址及热插拔隔离。
5. 真实 QProcess 使用本地模拟 worker 验证并发上限、队列、超时回收和退出；绝不请求外网。

7. 授权后只读验证当前公网出口与公开 IPv4/IPv6 测试地址归属，报告不保存本机公网地址。
8. 冻结包在空 Python/Qt 环境下验证内部入口和图形冒烟；未进行其他电脑实机兼容性测试。

## 0.10.1 运营商隐藏与自启动菜单隔离

1. 未查询到公网 IP 时标题和值均不可见；有效 IP 恢复后显示，归属失败不隐藏已确认 IP 的运营商行。
2. 多网卡、热插拔、断网/恢复和字体放大场景下可见性正确、无裁切；内容高度收紧，屏幕受限时不要求窗口超出可用尺寸。
3. 启用时 NoDisplay=true/Hidden=false，禁用时 NoDisplay=true/Hidden=true；desktop 格式合法且开关仍可读取。
4. 旧文件迁移保留状态、命令及附加字段；首次运行不创建，符号链接/写失败拒绝且不通知缓存。
5. Qt D-Bus 刷新异步、1500 ms、有总线才发送、不启动缺席服务；临时配置测试不得影响真实桌面。
6. 用户授权后备份当前软件项，清理旧缓存；可临时启用验证 NoDisplay 和 AutoStart，finally 恢复原状态；确认应用目录与排列缓存不再含本软件图标。
7. 单文件自检及临时目录 GUI 冒烟验证 QtDBus 打包、运营商行隐藏、NoDisplay 与既有设置行为；不把未重启登录或其他电脑测试记为通过。
