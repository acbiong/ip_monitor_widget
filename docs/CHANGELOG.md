# 变更履历

## 0.6.0 - 2026-09-20

### 功能

- 托盘右键菜单新增关于页面，展示软件版本、开发者信息、Git 分支/提交/状态和编译信息。
- 初始化 Git 仓库、主分支和功能分支流程，新增编译临时文件及发布输出忽略规则。
- 构建过程将 Git 和编译快照嵌入单文件，目标电脑无需安装 Git 也能查看构建信息。

## 0.5.1 - 2026-09-20

### 修复

- 修复桌面监视器窗口出现在任务栏的问题；主窗口改为 Qt 工具窗口类型，只保留系统托盘入口。
- 设置窗口归入主窗口组，避免设置对话框在支持任务栏的桌面环境中创建额外入口。
- 保留无边框、固定置底、鼠标穿透、拖动和位置记忆行为。

## 版本规则

- 基础版本使用 `MAJOR.MINOR.PATCH`。
- 不兼容变更递增 `MAJOR`；新增兼容功能递增 `MINOR`；BUG 修复、性能、文档和打包修复递增 `PATCH`。
- 每次执行 `src/packaging/build.sh` 自动递增构建后缀，格式为 `+build.YYYYMMDD.N`，例如 `0.5.0+build.20260920.1`。
- 基础版本由 `src/packaging/version_manager.py --set-base-version` 修改；构建后缀不得手工修改。

## 0.5.0 - 2026-09-20

### 功能

- 完成多网卡本机 IP、公网 IP 独立查询和默认出口网卡显示。
- 完成透明无边框桌面监视器、字体/透明度实时预览、取消回滚和默认设置恢复。
- 完成窗口位置记忆、托盘操作、锁定鼠标穿透和固定置底。
- 完成 PyInstaller 单文件交付、原生依赖审计、传输包和 SHA256 校验。
- 新增项目目录分类、测试计划/报告分离、开发规格书和 AI 编程规范。

### 修复

- 修复公网 IP 长时间“获取中”、跨网卡错误复用公网 IP、设置窗口关闭告警和退出缓慢问题。
- 修复字体缩放导致窗口裁切、透明度影响设置窗口、位置恢复和桌面窗口遮挡普通软件问题。

### 构建

- 发布基线：deepin 25 x86_64、glibc 2.38+、X11 或可用 XWayland。
- 当前基础版本保持 `0.5.0`；实际可执行文件版本由构建脚本追加 build 后缀。
