# 变更履历

## 0.10.1 - 2026-09-21

### 修复

- 未取得公网 IP 时隐藏运营商标题和数值整行；IP 恢复后自动显示，隐藏时重新计算内容高度。
- 自启动启用/禁用项均写入 NoDisplay，保存后异步刷新 deepin 应用目录，避免开始屏幕出现软件图标。
- 新版启动时修补已有启动项，保留启停状态与命令；不创建首次运行的启动项、不触碰其他软件。
- 当前电脑残留图标已清除；真实验证启用时 NoDisplay=true、AutoStart=true，测试后恢复原有关闭状态。
- 新增 12 项回归并扩展运营商布局测试，全部 124 项通过。详见 `test_reports/LAUNCHER_VISIBILITY_REPORT.md`。

## 0.10.0 - 2026-09-21

### 功能

- 每网卡公网 IP 新增独立运营商中文行，双栈分行，悬停显示对应地址、登记名称和 ASN。
- 查询、异步调度、显示格式拆分为独立模块；按确认地址查归属，不更改网卡绑定规则，不借用其他出口 IP。
- 增加有界并发、成功/失败缓存、8 秒看门狗、响应大小限制、旧地址隔离及退出清理；失败不影响有效公网 IP。
- 新增 22 项离线回归，总计 112 项通过；当前无线公网出口实测识别为中国电信。详见 `test_reports/OPERATOR_REPORT.md`。

## 0.9.0 - 2026-09-20

### 功能

- 设置页新增默认关闭的“开机启动”开关，保存后在当前用户登录图形桌面时启动。
- 独立 autostart 模块管理 XDG 启动项，支持单文件及源码路径、安全转义、原子写入与明确错误反馈。
- 取消不更改启动项，还原默认取消勾选后待保存；不需要管理员权限，不改其他启动项。
- 新增 20 项回归，合计 90 项通过；系统 desktop 校验及 Gio 特殊路径启动验证通过，见 `test_reports/AUTOSTART_REPORT.md`。

## 0.8.0 - 2026-09-20

### 功能

- 设置页新增“公网 IP 获取间隔”，默认 60 秒，可调 10–3600 秒，与系统指标刷新周期独立。
- 支持间隔实时预览、保存记忆、取消回滚及恢复默认；其他设置变化不重置公网倒计时。
- 保持本机 IP 不变时仍周期更新公网 IP，保留查询防重入、异步退出和网卡隔离。
- 新增 10 项配置/定时更新回归，总计 70 项通过；详细记录见 `test_reports/PUBLIC_IP_INTERVAL_REPORT.md`。

- 新增独立策略评估模块，区分标记流量、局部组网路由与实际默认/全网接管；保留安全拒绝及事务回滚。

## 0.7.1 - 2026-09-20

### 修复

- 修复 Tailscale 接管 DNS 时，将非回环 DNS 代理强制绑定物理网卡导致公网查询失败的问题。

## 版本规则

- 基础版本使用 `MAJOR.MINOR.PATCH`。
- 不兼容变更递增 `MAJOR`；新增兼容功能递增 `MINOR`；BUG 修复、性能、文档和打包修复递增 `PATCH`。
- 每次执行 `src/packaging/build.sh` 自动递增构建后缀，格式为 `+build.YYYYMMDD.N`，例如 `0.5.0+build.20260920.1`。
- 基础版本由 `src/packaging/version_manager.py --set-base-version` 修改；构建后缀不得手工修改。
